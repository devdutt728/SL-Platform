# SL Project Planner Frontend

Dedicated Next.js frontend for the planner workspace.

## Current UX scope

- summary metrics
- project filter
- planner board table
- create activity form
- status updates
- approve or reject actions
- archive action for allowed roles

## Run

1. Copy `.env.local.example` to `.env.local`
2. Point `BACKEND_URL` to the planner backend
3. Install packages with `npm install`
4. Start with:

```bash
npm run dev
```

Default local launcher port:

- `3004`

Base path:

- `/planner`
